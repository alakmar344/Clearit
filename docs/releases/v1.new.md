# Clearit v1.new

The first full release of Clearit — a real, on-device photo enhancer for Android 8.0+.

## Highlights
- ✨ **Auto enhance** that analyses exposure, white balance, noise and sharpness, then sets
  the sliders for you (adjustable strength and scope).
- 🎚️ **Manual control** with 17 professional sliders: Exposure, Contrast, Highlights,
  Shadows, Whites, Blacks, Temperature, Tint, Vibrance, Saturation, Clarity, Texture,
  Dehaze, Sharpening, Noise reduction, Color noise reduction, Vignette.
- 🎨 **11 presets**, all editable.
- 🔍 **Upscale 2×/3×/4×**, rotate and flip.
- 👀 **Before/after** split view and press-and-hold compare, pinch zoom, histogram.
- ↩️ Undo/redo, reset.
- 💾 Save full-resolution **JPEG / PNG / WebP** to `Pictures/Clearit`, share instantly.
- 🔒 100 % offline — no internet permission.

## Install
Download **`clearit-v1.new.apk`** below and open it on your Android phone. Verify with the
`.sha256` file if you like.

## Notes
- Video enhancement has been removed (the old implementation only copied files).
- Maximum output size depends on your phone's memory and is shown in *Size & Rotate*.
